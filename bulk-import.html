How duplicates are detected

A row is skipped if its name OR contact already exists — in the uploaded file or in the church database.

  • Names are compared ignoring capitalisation, spacing, punctuation and leading list numbers.
  • Truncated names such as Nam... Gideon match Namutamba Gideon.
  • Names are saved with the first letter of every word capitalised.
  • Contacts are compared using the last 9 digits, so +256 700 123456 matches 0700123456.
  • Writes are done in safe chunks and never overwrite an existing record.
